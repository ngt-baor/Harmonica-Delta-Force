# Harmonica Delta Force

**Version 1.1.7**

A desktop app for managing harmonica scores and playing them automatically in Delta Force.

The app organizes harmonica scores, lets you preview and manage your music library, and plays selected scores in the game.

## Download

Download [Harmonica Delta Force.exe](Harmonica%20Delta%20Force.exe) and run it on Windows. No separate Python installation is needed.

## Help and settings

Use the menu in the app to switch between the compact and advanced interfaces or open the usage guide. App settings are available from the settings control.

Your settings and music library are stored under `%APPDATA%\GTIHarmonica`.
